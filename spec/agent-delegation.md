# Граница делегирования

DeepSeek Harness управляет дочерними сессиями подписочного плагина. Каждый
запуск Codex, новый или возобновлённый, выполняет задание напрямую:
`multi_agent` и `multi_agent_v2` отключаются только в аргументах процесса.
Для отдельного исполнителя нужно создать отдельный дочерний чат в Harness.

Плагин сохраняет привязку к аккаунту и идентификатору сессии Codex,
передаёт завершённые сообщения и вывод инструментов в дочерний чат.
Настройки Codex за пределами плагина и запуск Claude Code не меняются.

Для совместимости с событиями старых сессий: `wait` без адресатов,
состояний и ошибки не попадает в ленту. Если эти данные приходят только
при завершении вызова, лента получает одну пару «вызов → результат»
с фактическими данными. Завершение `wait` не завершает ход.

Прошлые чаты не переписываются. Исправление не меняет поведение при
сетевых переподключениях, не запускает повторно отменённые задания
и не переключает аккаунты.

Приёмка: `node --test`, затем короткий smoke в приложении на задаче
без внешних инструментов (например, попросить описать один локальный файл).
В дочернем чате должны быть видны результат и ответ на уточнение в том
же чате. Запуск через подписку проверяется отдельно от unit-тестов.
