# Подписки в селекторе модели

- Штатный селектор и `/model` показывают профиль каждого включённого подписочного аккаунта, который прошёл проверку входа и CLI. Codex и Claude Code отображаются отдельными группами. Название указывает провайдера и профиль, а конкретную модель выбирают настройки официального CLI.
- Статус входа, включение, выключение, переименование и удаление обновляют каталог без перезапуска. Текущая занятость и квота не убирают строку из каталога.
- Обычный чат выполняет запрос на выбранном аккаунте без API-ключей, автоматических повторов и переключения на другой аккаунт или API. Сбой, отсутствие CLI и исчерпание лимита возвращаются как ошибки.
- Обычные чаты не привязывают вендорскую сессию: каждый ход передаёт актуальный текст и до 80 000 символов видимого текстового контекста. Можно менять провайдера между ходами; выбор отправляет контекст этого чата выбранному провайдеру. Вложения текущего запроса не поддерживаются. Служебные сообщения и сырые результаты инструментов не включаются в контекст. Подписочный дочерний чат сохраняет прежнюю привязку к аккаунту и CLI-сессии.
- CLI выполняет команды в рабочем каталоге проекта по существующим правилам плагина и требует режим Harness «Полный доступ». Селектор не повышает права. Инструменты CLI записываются в историю, но не исполняются второй раз ядром Harness.
- Для обычного и дочернего чатов текст CLI передаётся штатными блоками потока Harness. Так итоговый ответ отображается в самом ходе, а не остаётся скрытой записью в журнале. Если CLI завершился без текста, ход показывает ошибку вместо пустого успешного завершения.
- Несвязанные с ходом вспомогательные вызовы не записывают результат в чат. Подключение и подтверждение подписки остаются в панели «Подписочные агенты».
